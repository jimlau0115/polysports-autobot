☁️ Railway + GitHub 24/7 全天候雲端部署指南

為什麼選擇 Railway？Vercel Serverless 會在數秒後休眠中斷，而 Railway 支援 24/7 常駐背景掃描與即時下單

步驟 1：推送專案至 GitHub

本專案已內建完整 Dockerfile、railway.json、Procfile 與 requirements.txt。在專案資料夾執行：

git init
git add .
git commit -m "Initial PolySports 70%+ Auto-Trading System"
git branch -M main
git remote add origin https://github.com/<您的帳號>/polysports-autobot.git
git push -u origin main

步驟 2：在 Railway 一鍵連接 GitHub 倉庫

  1. 登入 Railway.app，點擊 New Project → Deploy from GitHub repo。
  2. 選擇剛建立的 polysports-autobot 倉庫，Railway 會自動偵測 railway.json 與 Dockerfile 並啟動常駐服務。
  3. 在 Railway 服務的 Settings → Networking 點擊 Generate Domain 即可獲得您的專屬監控網址！

步驟 3：環境變數設定 (Railway Variables)

若要啟用真實下單，可在網頁右上角「CLOB 錢包設定」輸入，或在 Railway 的 Variables 設定：

TRADING_MODE=PAPER
DATA_SOURCE_MODE=AUTO
MIN_WIN_PROB=0.70
MAX_WIN_PROB=0.95
BET_AMOUNT_USDC=25
POLY_PRIVATE_KEY=0x您的Polygon私鑰
POLY_FUNDER_ADDRESS=0x您的Polymarket代理地址
POLY_SIGNATURE_TYPE=1
